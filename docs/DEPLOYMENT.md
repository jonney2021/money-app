# 部署与 iPhone 安装

没有 Mac 或 Apple Developer 账号时，使用 PWA。它通过 Safari 添加到主屏幕，使用独立窗口，首次加载后支持离线记账。这里没有创建公网部署，也没有开通任何付费服务。

## 方案 A：先使用免费本机账本

`public/` 是独立静态网站，可以托管到支持 HTTPS 的静态网站平台。无须编译，发布目录选择 `public`。

### 使用 GitHub Pages（你当前选择的免费方式）

仓库已提供 `.github/workflows/pages.yml`，只有手动运行才会发布，不会因推送而自动公开网站。

1. 将本次代码推送到 GitHub 仓库。
2. 打开仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
3. 打开 **Actions → Publish iPhone app to GitHub Pages → Run workflow**，选择 `master` 并运行。
4. 工作流成功后，在 Pages 设置页或工作流 deployment 中打开 GitHub 提供的真实网址。
5. 用 iPhone Safari 打开这个网址，再添加到主屏幕。

GitHub Pages 的可用性取决于仓库可见性与 GitHub 套餐；个人免费账户通常使用公开仓库。请不要为了发布而把含私人数据的仓库直接改为公开。`public/` 仅含应用代码，切勿把账本备份、密钥或邮件上传进去。当前尚未运行该工作流，也尚未验证公网地址。

静态托管支持完整的本机收支、统计、预算和备份功能，**不支持邮件后台 API**。「邮件」页的同步只有在部署完整 Node 后台时才会成功。

## 方案 B：包含 Gmail 后台

选择支持 Node.js 22+ 和持久化磁盘的 HTTPS 托管平台，或自己的服务器。以下是通用配置：

| 设置 | 值 |
| --- | --- |
| 仓库根目录 | money-app 仓库根 |
| 构建命令 | 无，或 `node --check server/index.js` |
| 启动命令 | `npm start` |
| 健康检查路径 | `/api/health` |
| `PORT` | 平台提供；本地默认 3000 |
| `EMAIL_WEBHOOK_SECRET` | 你在平台安全设置中填写的随机密钥 |
| `DATA_DIR` | 持久化磁盘挂载路径下的目录 |

**费用：**许多平台的持久化磁盘或持续运行后台需要付费。请在供应商确认价格后再创建资源。本仓库未配置自动开通付费资源。

不要部署到丢弃文件系统的 Serverless Function，也不要把邮件交易写到没有持久化的临时磁盘。当前文件存储仅支持一个服务实例；不要开多副本。生产数据请定期在托管平台备份。若要多用户账号及家庭云同步，需要后续加入数据库和用户鉴权。

平台应提供有效 HTTPS；不要在浏览器与服务器之间使用 HTTP 发送密钥。不需要另外开放数据库端口，不要把 `data/` 作为静态目录发布。

## 验证

- 打开 HTTPS 根网址，应显示小满账本；健康接口返回 `{"ok":true}`。
- 不带密钥读取 `/api/email/transactions` 应返回 401。
- 用一封测试消费通知检查导入、重复同步、人工确认；重启服务后邮件交易应仍保留。
- 在 Safari 记一笔、关闭再打开，检查记录仍存在；导出 JSON 备份后妥善保管。
- 首次在线打开后开启飞行模式，确认记账仍可用。邮件同步需要联网。

## 安装到 iPhone

1. 用 **Safari** 打开你部署后的 HTTPS 地址。
2. 点击分享按钮 → 「添加到主屏幕」→ 添加。
3. 从主屏幕的小满图标打开。

网站部署或域名变化不会自动迁移本机数据，先导出备份再切换。不同 Safari / 主屏幕安装上下文或 iOS 版本可能有不同的存储行为，安装后请验证数据并保留备份。
