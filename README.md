# 小满 · 家庭账本

适合 iPhone 日常使用的中文家庭账本 PWA，默认加元 CAD。无需 Mac、Apple Developer 账号或 App Store 安装。部署 HTTPS 后，在 Safari 中打开 → 分享 → 添加到主屏幕。

## 已实现

- 收入、支出、分类、日期、备注的新增 / 编辑 / 删除。
- 月份筛选、收支汇总、分类占比、月度预算。
- 本机保存、JSON 备份和恢复；首次联网加载后可离线记账。
- Gmail 消费通知脚本、后台识别、消息 ID 去重、待确认交易同步。
- 安全默认：未配置密钥时邮件 API 关闭；邮件原文不落盘；币种不明或非 CAD 的邮件交易不会混入 CAD 账本。

## 本地运行

要求 Node.js 22 或更新版本，无第三方运行依赖。

```sh
npm start
# 开发时自动重启后台
npm run dev
# 解析、去重、持久化、真实 HTTP API 测试
npm test
```

默认端口 3000。无需编译或 npm install。前端文件在 `public/`，后台在 `server/`。

## 在 iPhone 使用

见 [部署和安装](docs/DEPLOYMENT.md)。仓库代码本身不是可安装的网址；需要先将网站部署到可从手机访问的 HTTPS 服务。当前没有发布到 App Store，也没有原生 IPA 安装包。

Gmail 配置见 [Gmail 自动记账](docs/GMAIL_SETUP.md)。邮件脚本需要用户自行授权 Gmail 和创建定时触发器，默认不会访问任何邮箱。

## 数据与限制

- 手动账本保存在当前设备的浏览器 `localStorage`，不是云端家庭协作账本。家人设备和新手机不会自动共享手动记录。Safari 清理数据、更换域名、卸载或更换设备可能丢失数据，请定期导出。
- 服务端仅保存邮件识别出的交易到 `DATA_DIR/transactions.json`，必须使用持久化磁盘。它不是所有手动记录的云端备份。
- 账本页面没有账号系统；手机可访问该网站时，展示的是该设备本地数据。邮件接口采用一个私人共享密钥，不适用于公开的多租户服务。不要把密钥放在链接、代码或 Git 中。
- Apps Script 需要 Gmail 读取权限。符合查询条件的邮件正文会通过 HTTPS 发给你部署的后台进行识别，但后台不存储正文。请按真实银行发件人与通知标题缩小查询范围。
- 识别支持部分中英文交易格式，不能保证适配所有银行。所有邮件交易需人工核对后确认。`$` 无法确定是 CAD 或 USD，会跳过；可以手动录入。账单、还款通知会排除，退款、冲正、外币换算不自动处理。
- Google 定时任务受配额与执行时间限制，当前每次扫描最近 7 天最多 100 个会话。长时间停用后需要人工核对缺漏。
- 这是可运行的第一版，不包含银行直连、自动扣款或真正的后台 iOS 进程。App 关闭时邮件读取由 Google 定时任务执行，打开 App 后点击同步。

## 结构

```
public/               手机网页和离线缓存
server/               Node HTTP 服务、通知识别、持久化
integrations/gmail.gs  用户 Google 账号内运行的脚本
test/                 Node 内置测试
```
